# Loyiha hujjatlari

## Modullar

| Fayl | Vazifasi |
| --- | --- |
| `src/main.py` | `salomlash(ism)` funksiyasi va dasturga kirish nuqtasi `main()` |
| `tests/test_main.py` | `salomlash()` uchun unit testlar (`unittest`) |

## Muhit

- Python 3.10 yoki undan yangi
- Visual Studio Code + Python kengaytmasi
- Git 2.40+

## Ishlab chiqish jarayoni

1. `develop` branch'idan yangi `feature/<nom>` branch ochiladi.
2. O'zgarishlar Conventional Commits formatidagi commitlar bilan saqlanadi (`feat`, `fix`, `docs`, `test`, `chore`, `refactor`).
3. Ish tugagach, `develop`'ga Pull Request ochiladi va ko'rib chiqilgandan so'ng birlashtiriladi.
4. Barqaror holatdagi `develop` `main`'ga birlashtiriladi.
